## 🚀 Как пользоваться

### Первый вход

1. Открой ссылку: `https://daniil022.github.io/sk-terminal/`
2. Появится **список сотрудников**
3. Кликни на **Администратор**
4. Введи пароль: **`admin2026`**
5. **Смени пароль** в 👑 ADMIN → 🔑 (на своей строке)

### Добавить сотрудников

1. Зайди как админ
2. Открой вкладку **👑 ADMIN**
3. Заполни:
   - **Логин:** латиница без пробелов (например `ivanov`)
   - **Имя:** русское (например `Иванов И.И.`)
   - **Роль:** Сотрудник
   - **Пароль:** оставь пустым → сгенерируется
4. Нажми **➕ Создать**
5. **Скопируй пароль** из всплывающего окна и передай сотруднику
6. **⚠️ Пароль показывается только один раз!**

### Сотрудник заходит

1. Открывает ссылку
2. Находит себя в списке
3. Кликает → вводит пароль → входит

### Синхронизация

**Каждый пользователь должен подключиться к облаку:**

1. Зайди как админ
2. На дашборде нажми **☁️ Подключиться к отделу**
3. Статус станет 🟢 Онлайн
4. Теперь все изменения летят всем, кто тоже подключён

## ⚙️ Как работает

- **Данные хранятся в localStorage браузера** (не теряются при F5)
- **Синхронизация через Firebase Firestore**
- **Пароли хэшируются** (простой хэш, не крипто — для игры достаточно)
- **Экспорт/Импорт JSON** — резервная копия

## 🔧 Как обновлять

1. Редактируй нужный файл в GitHub
2. Commit changes
3. Через 1-2 минуты GitHub Pages обновит
4. Обнови страницу (**Ctrl+F5**)
